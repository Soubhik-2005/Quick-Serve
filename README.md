QuickServe 🚀
-
QuickServe is a full-stack food ordering web application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).
The platform allows users to browse food items, manage their cart, and place orders through a responsive and interactive interface.

📌 Features
-
🍔 Browse available food items

🛒 Add and remove items from the cart

👤 User authentication (Signup / Login)

📦 Order placement functionality

⚡ Responsive and interactive UI

🔐 RESTful API built with Express and Node.js
